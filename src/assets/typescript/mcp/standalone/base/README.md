This is an MCP server generated by the AgentCore CLI!

## Tools

- `add_numbers` - Add two numbers together
- `multiply_numbers` - Multiply two numbers together
- `greet_user` - Greet a user by name

## Developing locally

`agentcore dev` will start the MCP server locally.

## Deployment

`agentcore deploy` will deploy your MCP server to Amazon Bedrock AgentCore.
